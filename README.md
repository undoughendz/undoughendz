### hey, i'm undoughendz 👋

Hey, I'm undoughendz — I build web tools and tiny utilities mostly with TypeScript, Node.js, and React, usually glued together with Express and a SQLite database that's doing more than it probably should. I'm drawn to indie web projects and serverless setups where you can go from idea to deployed thing in an afternoon. I like pragmatic code over perfect code, and I firmly believe most apps need about 60% fewer dependencies than they ship with.

- 🔭 Building a lightweight serverless toolkit that stays out of your way.
- keeps notes about indie web projects that will never be published
- rewrites it once, then leaves it alone
